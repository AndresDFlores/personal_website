Introduction to LEDs


I created the deck below as part of my Introduction to LEDs workshop hosted at the MakerFX Makerspace. This workshop is designed as a continuation of the material presented at my Introduction to Python course, using Python to design LED routines for addressable RGB LED strips.


Since this workshop draws on the material covered in Intro to Python, it caters to beginner coders who are practicing foundational Python coding principles to implement addressable LED code. This workshop focuses solely on software design, so hardware is not required to participate.


I designed an addressable LED simulator that implements students' LED code so they can see their designs come to life. The simulator is designed to imitate real-world addressable LED code implementation without configuring hardware. Since the makerspace is comprised of varying technical skill levels, I wanted to make the workshop accessible to members who are new to coding but might not have exposure to electronics hardware yet.


The code for the LED simulator is publicly available on my Github!
